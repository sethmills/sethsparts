Why the app keeps its own copies

Datasheets for obscure parts disappear constantly. Small manufacturers redesign their websites, hobby shops close, forum attachments rot, and a product page that worked last year returns a 404 today.

A link is not a document. So when you give the app a link, it fetches a copy and keeps it, and the copy becomes what the app shows you. The original address stays alongside as provenance — you can still see where it came from, and you're never depending on it.

This applies to reference documents and to part attachments alike. Scanning a datasheet to a file still works and is often the better answer for something you care about.

What it won't archive

Repurchase links. Those are a live action, not a document — a saved copy of a product page would show a stale price, which is worse than no page at all.

It also won't pretend. If the source sits behind a login wall or blocks automated requests, the document stays a link and says the archive failed and why. You'll see “archive failed: the source returned HTTP 403” rather than a cached copy that quietly isn't there.

If you've already got a good copy, a later failed refresh will never throw it away.

Organising your library

Categories are yours — rename them, add your own, reorder them, delete the ones you don't want. Nothing is baked in.

Some groupings that hold up:

  • By discipline — Electronics, 3D printing, Woodwork. Best when different people use the bench.
  • By job — Pinouts, Wire and connectors, Consumables. Best when you're usually looking for a kind of answer rather than a subject.
  • By machine — one shelf per printer or lathe. Best when a machine has its own particular reference material.

A shelf with three things on it is worth having. Waiting for a category to fill up before creating it means the first three documents end up somewhere wrong.

Starting from scratch, or from a set

Setup offers a starter set of 27 references — resistor colour codes, common pinouts, wire gauge charts, soldering guides, 3D printing troubleshooting. They're generic reference material rather than anyone's personal notes.

Take them, ignore them, or take them and delete two thirds. Loading the set is a one-off: it won't put back anything you've since removed.

The shipped set contains links only. Each install fetches its own copies of what it chooses to keep.

Bulk-fetching the copies

After loading the starter set, nothing has a local copy yet. Use Archive the next 5 on the setup page, or run python manage.py archive_documents to fetch the lot with a polite pause between requests.

Some will fail. That's expected and recorded — a dead link is information, not an error you have to fix.
