Labels

The app renders labels itself and sends the finished bytes to a small print bridge running on a Raspberry Pi next to your printer. It never needs a printer driver on the machine running the app, which is how it works from a container or a laptop.

Label stock sizes

Sizes are defined in inventory/label_printing.py as LABEL_SIZES — height, width and how dense the printer is. The defaults match the three sizes this was built around; edit that dictionary to match the stock you actually buy, and every label in the app follows.

If your printer is a different resolution, its dots-per-inch matters: the renderer is set for 203 dpi, which is what a GK420T and most desktop label printers use.
