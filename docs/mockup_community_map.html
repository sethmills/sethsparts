What others see of you: an anonymous pin at postcode-area level, nothing else.
On the map is not the same as sharing parts. The default connection exchanges pins only. Nobody can search your inventory unless you agree separately, person by person.
If the default connection goes away, connect with any other workshop and the map starts updating again.
Fully open source stack, nothing to sign up for: MapLibre GL (the open-source fork of Mapbox GL) for the map, OpenFreeMap for vector tiles — free public instance, no API keys, no limits, no cookies, and the whole production setup is open source so it can be self-hosted — and OpenStreetMap for the data.
